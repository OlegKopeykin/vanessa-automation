# builds/8.3.6/ — старая платформа 8.3.6

> Платформа 1С 8.3.6 (32-bit, x86). Используется для:
> - **CheckDoc** (проверка документации) — `uf-checkdoc.json`
> - **Compat-режим 8.2 OF** — см. `compat-8.2/of-fast.json` (физически тоже на 8.3.6, но семантически compat-test)

## Список builds

| Build | Эквивалент | Используется в |
|---|---|---|
| `uf-checkdoc.json` | `VBParams836UFCheckDoc.json` | `presets/doc/default.json` |

## Параметры платформы

- **Версия**: 8.3.6
- **Точная сборка на Jenkins-ноде**: 8.3.6.2530
- **Архитектура**: 32-bit (`C:\Program Files (x86)\1cv8\8.3.6.2530\bin\1cv8.exe` — толстый клиент)
- **Сервисная база**: `tools/ServiceBases/v83ServiceBase836`

## Особенности

- Запускается через `1cv8.exe` (толстый клиент), не `1cv8c.exe`
- Самая старая поддерживаемая 8.3.x — для compat-валидации документации
- Тег `@IgnoreOn836` (164 файла) пропускается на этой версии

## Связь с `compat-8.2/`

Папка `compat-8.2/of-fast.json` тоже физически запускается на 8.3.6, но это **compat-test** для режима совместимости с 8.2 (другая семантика). Поэтому эти builds разнесены по разным папкам по семантическому признаку.
