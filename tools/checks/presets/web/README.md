# presets/web/ — веб-клиент

> Проверки в режиме веб-клиента 1С (через браузер).

## Список пресетов (целевой)

| Пресет | Эквивалент |

## Особенности веб-проверок

- Запускается реальный браузер (Chrome/Firefox)
- Тесты помеченные `@IgnoreOnWeb` (381 файл) пропускаются
- Дополнительные параметры в build: `WebClient`, `BrowserType`, и т.д.
- Сильно медленнее серверных проверок

## Как использовать

```bash
# Целевой синтаксис
oscript tools/checks/check.os web/8327

# Сейчас — через старый
tools\WebCheck_8327.cmd
```
