# presets/doc/ — проверка документации

> Проверка корректности документации VA, не связана с тестированием функционала.

## Список пресетов (целевой)

| Пресет | Эквивалент |
|---|---|
| `default.json` | `tools/JSON/CheckDoc.json` |

## Что проверяется

- Корректность ссылок в документации
- Совместимость snippets с актуальными API
- Соответствие документации текущей версии VA

## Как использовать

```bash
# Целевой синтаксис
oscript tools/checks/check.os doc/default

# Сейчас — через старый
tools\CheckDoc.cmd
```
